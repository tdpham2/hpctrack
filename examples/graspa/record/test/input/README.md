# Supply a private validation input

This directory intentionally contains no scientific dataset. In your private
record, add simulation.input and its required structure and force-field files.
Use a small calculation that fits the approved walltime, for example 5,000
initialization and 5,000 production cycles with zero equilibration. Record the
chosen cycle counts and random seed in the private NOTES.md.

Do not copy outputs, restart files, credentials or unrelated working files.
The public example cannot validate gRASPA until these inputs are supplied.
